# 产品工艺复制式新增设计

## 背景

同一设备下，不同产品工号通常共用产品头、焊点头和测试项区的 PLC 地址结构。当前“新增”会生成固定默认值，用户必须为每个产品工号重复录入全部地址和偏移配置。

## 目标

复用现有“新增”按钮：用户先选中一条产品工艺，再点击“新增”，系统创建一条未保存的新记录，并复制源记录的全部业务配置。用户只需修改产品工号以及少量确有差异的字段。

## 交互行为

1. 表格存在选中行时，“新增”以该行为模板。
2. 新记录暂时保留源产品工号，保证它在当前筛选结果中可见；用户保存前只需把产品工号改为目标值。
3. 新记录创建后自动成为当前选中行，原记录保持不变。
4. 未选中任何行时，继续使用当前的固定默认配置，保持原有新增能力。
5. 若用户未修改产品工号就保存，沿用现有“产品工号 + 工位”重复校验阻止误保存。

## 复制范围

复制测试方案、工位、焊点数量、采集点名称与表头、历史显示选项，以及产品头、焊点头、测试项区的所有基地址、长度和偏移表达式。

数据库身份字段不复制：`Id` 保持 `0`，创建时间和更新时间使用新记录的当前时间。这样保存时执行插入，不会覆盖源记录。

## 代码边界

- 在 `AutoWeldSystem.Core` 增加纯规则方法，显式创建副本，集中定义哪些字段属于可复制的业务配置。
- `AddressManageView` 只负责选择复制源、调用规则并刷新/选中新行。
- 不修改数据库结构、服务接口、权限码和 WinForms Designer 布局。

## 验证

- 回归测试验证所有业务字段被复制、身份字段被重置、修改副本不会改变源记录。
- 回归测试验证无源记录时仍能创建原有默认配置。
- 运行控制台测试项目和解决方案构建；保留当前工作区中与本功能无关的 Designer 改动。
