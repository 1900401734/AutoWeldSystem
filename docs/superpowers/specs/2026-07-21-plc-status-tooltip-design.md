# PLC 状态悬浮面板拟亚克力优化设计

## 背景

`MonitorView` 当前使用运行时创建的 WinForms `Panel + Label` 展示 PLC 连接详情和最近十条状态变化。面板继承页面的 10.5pt 字体，使用系统黄色提示背景、固定 520 像素最大宽度和无限高度；长诊断消息在高 DPI 下大量换行，使面板显得笨重并遮挡页面。

## 目标

- 保留现有悬停显示、定时刷新、状态历史和销毁流程。
- 使用项目已有的 `AntdUI.Panel` 呈现冷白色拟亚克力卡片，不实现真实背景模糊。
- 将正文调整为 9pt，并将历史记录由十条精简为最近五条。
- 面板尺寸和位置适配当前 DPI、窗口客户区及屏幕工作区。
- 将面板结构文字和 PLC 状态接入现有中英文资源；原始 PLC/HSL 诊断消息保持原文。
- 将版本从 `1.0.8` 更新到 `1.0.9`，并同步 `docs/QUICK_START.md` 的当前版本说明。

## 非目标

- 不新增依赖、顶层窗体、DWM/PInvoke 或自定义亚克力渲染层。
- 不改变 `IPlcCommunicationService`、PLC 状态发布频率或历史数据来源。
- 不翻译、改写或分类第三方和设备返回的原始诊断消息。
- 不修改 PLC 连接逻辑、生产流程或其他状态控件。

## 视觉与布局

运行时容器由标准 `Panel` 替换为项目已经引用的 `AntdUI.Panel`，继续复用现有文本标签。容器使用接近不透明的冷白背景、8px 圆角、轻阴影和低对比度边框，避免透明子控件带来的重绘闪烁。正文使用 `Microsoft YaHei UI` 9pt 和深灰前景色。

宽度、高度、内边距、圆角和阴影使用 96 DPI 下的逻辑值，并按 `DeviceDpi` 换算。面板优先显示在 PLC 状态标签下方；若右侧或底部空间不足，则在当前客户区和屏幕工作区内向左或向上调整，避免越界。面板高度由内容决定，不新增滚动或固定顶层窗口。

## 内容与国际化

当前详情保留工位、当前状态、连接状态、端点、最近连接时间、最近心跳时间和完整当前消息，移除每 500ms 变化但没有诊断价值的“当前读取时间”。

历史区只展示当前工位最近五条状态变化，每条使用紧凑格式：

```text
18:29:46  重连中  PLC reconnect retry waits 10s.
```

历史项不再重复完整日期、英文枚举值和“连接：是/否”。过长历史消息按可读长度截断并追加省略号；当前详情中的原始消息不截断，因此不会丢失最新诊断信息。

在 `TextKeys.Monitor` 下新增悬浮面板所需资源键，并在 `UiText.resx` 与 `UiText.en.resx` 中提供成对文本。状态名称继续复用现有 PLC 状态资源。语言切换沿用 `MonitorView.OnLanguageChanged()` 和 `ApplyAllStationStatuses()`，可见面板在下一次刷新时立即使用当前语言。

## 稳定性与错误处理

- 文本、客户区宽度和 DPI 均未变化时跳过尺寸重算。
- 面板仅在首次需要时创建，并沿用现有释放逻辑，避免每次刷新重建控件。
- 资源缺失时沿用本地化服务的现有回退行为，不阻止状态显示。
- 空端点、时间或消息继续显示 `--`。
- 原始诊断消息中的换行继续规范化为空格分隔，避免破坏历史单行布局。

## 测试与验收

- 回归测试验证容器使用现有 `AntdUI.Panel`，且未引入 DWM、顶层弹窗或新依赖。
- 回归测试验证历史上限为五条、紧凑时间格式、重复字段移除以及当前读取时间移除。
- 回归测试验证新增资源键在中文和英文资源中均存在，原始消息仍直接进入显示文本。
- 回归测试验证尺寸与位置计算包含 DPI 缩放和可用区域约束。
- 运行控制台回归 harness 和使用独立输出目录的解决方案构建。
- 手工检查 100%、125%、150% DPI 下的中英文显示、屏幕贴边定位和长诊断消息换行。

## 范围

实现仅涉及 `MonitorView`、本地化键与中英文资源、控制台回归测试、版本属性、`docs/QUICK_START.md` 及本设计说明。不修改 Designer 文件、PLC 服务接口和其他页面。
