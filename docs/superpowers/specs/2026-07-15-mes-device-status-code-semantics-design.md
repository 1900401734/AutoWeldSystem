# MES 设备状态 0/1 语义调整设计

## 目标

将 MES 设备生命周期状态统一为 `0=停机`、`1=开机`。

## 范围

- 仅调整 `ProductionConstants.MesDeviceStatuses` 中 `PoweredOn` 与 `Stopped` 的值。
- 保持调用方使用语义常量，避免在启动、退出和默认状态路径中出现硬编码状态码。
- 更新状态名称和格式化结果的回归测试，验证 `0` 显示为“停机”、`1` 显示为“开机”。
- 不调整 PLC 原始状态编码（运行、暂停、停机、报警）。
- 不迁移既有设备状态日志或历史 MES 上报记录。

## 设计选择

采用交换语义常量值的最小变更方案：`PoweredOn` 改为 `"1"`，`Stopped` 改为 `"0"`。
所有生命周期调用继续引用语义常量，因此软件启动自动上报 `1=开机`，退出自动上报 `0=停机`。

## 验证

先修改控制台回归测试并确认其按旧语义失败，再交换常量值，最后运行完整控制台测试和解决方案构建。
